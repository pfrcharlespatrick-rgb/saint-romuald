# Documentation du projet

Pour l'orientation générale — ce qu'est le projet, la règle des corrections
manuelles, la chaîne de publication — voir **`CLAUDE.md`** à la racine du dépôt.

## Documents vivants

| Document | Contenu |
|---|---|
| `SCHEMA.md` | Le dictionnaire de données : tables, champs, valeurs admises, conventions d'identifiants. **La référence.** |
| `FILIATION.md` | L'annexe des filiations : rapprochements calculés, degrés de confiance, primauté des preuves documentaires. |
| `LIEUX.md` | Le modèle des lieux : pourquoi un numéro de maison du recensement ne se plaque pas sur une adresse actuelle, flux carte ↔ atelier. |
| `RELECTURE-1881-D1.md`, `RELECTURE-1881-D2.md` | État de la relecture au manuscrit de 1881, division par division. |
| `RELECTURE-1881-D2-questions.md`, `RELECTURE-1891-D1-questions.md` | Journaux des lectures difficiles en attente d'arbitrage du chercheur. |
| `REFONTE.md` | L'identité visuelle du site (jetons, typographie, écrans). La refonte qu'il planifiait est livrée ; il reste la référence de design. |

## Archive

`archive/` garde les documents dont l'objet est accompli, pour mémoire :

- `TRANSFERT.md` — le brief de transfert initial vers Claude Code (l'état du
  projet qu'il décrit est dépassé) ;
- `GUIDE-ETAPE1.md` — la mise en ligne initiale sur GitHub Pages, faite ;
- `HEBERGEMENT.md` — le tour d'horizon d'hébergement qui a mené à ce choix.
